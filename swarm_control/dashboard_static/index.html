Connect a local repository

The repository must already be downloaded on the computer running Swarm Control. Paste its full folder path or the path to its swarm.toml. A GitHub URL is not a local folder.

Linux / WSL: /home/you/projects/my-repo · macOS: /Users/you/projects/my-repo. Spaces are allowed; omit surrounding quotes.

My repository has no swarm.toml yet

A project needs its own swarm.toml, task files in swarm/tasks/, Git history and a matching GitHub origin. Prepare those using the beginner guide in this download: docs/QUICKSTART.md. Connecting validates these files and preserves existing run history.

To try the included example first, run these commands from the controller folder, then connect the new swarm-demo folder here:

./.venv/bin/python examples/create_demo.py ../swarm-demo
